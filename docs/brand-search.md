# Google 品牌词观察：Zhemin

目标是加强 `Zhemin`、`Zhemin Lin` 与 `https://www.zhemin.ltd/` 的对应关系，同时观察中英文首页的搜索表现。姓名和经历以现有公开资料为准；结构化数据的简介复用首页可见的首段介绍。

## 2026-10-16 基线

同一浏览器使用 `pws=0` 抽查 Google 第一页，按普通网页结果计数，排除图片和 AI 概览。参数不代表覆盖该地区所有用户，也不是持续排名数据。

| 查询 | `hl=en&gl=us` | `hl=zh-CN&gl=sg` |
| --- | --- | --- |
| `zhemin` | 第一页未见主站 | 第一页未见主站 |
| `Zhemin Lin` | 主站约第 3 位 | 主站约第 5 位 |

此前 Search Console 主站全部查询的 3 个月平均排名为 8.8，数据范围为 2026-07-15 至 2026-10-13。这个数值不能用作 `zhemin` 的排名。

## 每周检查口径

在已验证的 `sc-domain:zhemin.ltd` 属性中，使用网络搜索、最近完整的 28 天，并与前 28 天比较。排除尚未完整处理的日期，记录后台实际使用的起止日期。

1. 网页使用自定义正则 `^https?://(www\.)?zhemin\.ltd/`，排除研究项目子域名。
2. 分别使用“完全匹配”的查询过滤器 `zhemin` 和 `zhemin lin`，不将两者合计当作简称表现。
3. 记录点击、曝光、CTR 和平均排名；查看网页、国家/地区和设备维度。
4. 在网页维度分别检查 `https://www.zhemin.ltd/` 和 `https://www.zhemin.ltd/cn`。中文首页曝光尚未出现时，另看 URL Inspection 的索引状态。
5. 查询或维度行未显示时记为“未显示／数据不足”。隐私过滤可能隐藏低频查询，不把缺失值写成零。

同周复查以上四组 Google 搜索，保留相同参数、第一页普通网页结果、实际显示的地区、日期和目标 URL。登录状态、IP、语言及搜索布局都会影响结果；手动抽查与 Search Console 平均排名分别记录。
